# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and assume good intent. Critique ideas, not people.
- Welcome newcomers. A first PR that needs work deserves a kind review.
- Disagree with evidence: link the HIG page, WWDC session or device screenshot.
- No harassment, insults, sexualized content, personal attacks, or publishing others' private information.

## Scope

Applies in all project spaces (issues, pull requests, discussions, reviews) and when representing the project elsewhere.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@imtiyazakiwat](https://github.com/imtiyazakiwat), using the contact details on their GitHub profile. Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove comments, commits and issues, and may warn, temporarily ban or permanently ban contributors, following the Contributor Covenant [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
